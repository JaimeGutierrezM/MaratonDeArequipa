## Planes Iniciales de Entrenamiento

| Plan | Duracion / Enfoque | Validacion |
| :--- | :--- | :--- |
| **Empezar a Correr** | 6-8 semanas • Principiante | Entrenador + aviso medico |
| **Primer 5K / Mejorar 5K** | 6-8 semanas | Ritmos y carga revisados |
| **Primer 10K / Mejorar 10K** | 8-10 semanas | Incluye fuerza y recuperacion |
| **Primer 21K** | 12-16 semanas | Adaptacion progresiva a la distancia |
| **Preparacion para Altura** | Modulo transversal | Especial atencion a runners visitantes (2,335m) |
| **Recuperacion Post-Carrera** | 7-14 dias | No sustituye atencion medica |
